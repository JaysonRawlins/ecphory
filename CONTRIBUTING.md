# Contributing

**Issues yes, pull requests no.**

Bug reports, questions and feature ideas are all welcome as
[issues](https://github.com/JaysonRawlins/ecphory/issues). That is the way
in, and it is genuinely read.

Unsolicited pull requests are closed by a workflow, including good ones.
Please don't spend an evening on a patch and get a robot for it. If an issue
discussion reaches the point where code is the obvious next step, you will
be asked for a PR, and then it is welcome.

This is a single-maintainer project and the policy is about review capacity,
not about the quality of your patch.

## If a closed PR sent you here

Nothing is wrong with your change. Open an issue describing the problem it
solves and link your branch from it. That costs you nothing and puts the
idea where it will actually be considered.
